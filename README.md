# Mansa Musa Gold Machine

A browser-playable claw-style mini game themed around gold, trade, and scholarship associated with Mansa Musa and the Mali Empire.

## Run locally

### Python

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Controls

- Left / Right arrows: move the claw
- Space or Up arrow: drop the claw
- On-screen buttons also work
